# Smart Grocery Management System

A full-stack grocery management application built using:

- React.js
- Spring Boot
- MySQL
- JWT Authentication
- Tailwind CSS

---

## Features

- User Authentication
- Role-Based Access
- Inventory Management
- Orders Management
- Reports & Analytics
- Dashboard
- Responsive UI

---

## Tech Stack

### Frontend
- React
- Tailwind CSS
- React Router
- Axios

### Backend
- Spring Boot
- Spring Security
- JWT
- JPA / Hibernate

### Database
- MySQL

---

## Setup Instructions

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
mvn spring-boot:run
```

---

## Database

Import:

```txt
grocery_db.sql
```

into MySQL.
